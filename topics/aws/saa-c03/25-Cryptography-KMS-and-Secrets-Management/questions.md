# Questions - Cryptography, KMS and Secrets Management

## 1)
An application needs to rotate database password automatically without major refactoring. Best option?

A. Parameter Store Standard
B. Secrets Manager
C. ACM
D. CloudHSM

Answer: B

## 2)
Which option provides greater control over key policy and lifecycle?

A. AWS-owned key
B. AWS-managed key
C. Customer-managed KMS key
D. S3-managed key only

Answer: C

## 3)
To use a certificate with CloudFront, in which region must the ACM public certificate be created?

A. sa-east-1
B. us-west-2
C. us-east-1
D. eu-west-1

Answer: C

## 4)
Which service is most suitable for storing configuration parameters at reduced cost with SecureString option?

A. Secrets Manager
B. Parameter Store
C. IAM
D. CloudTrail

Answer: B

## 5)
In KMS, which element is mandatory for primary key access control?

A. Security Group
B. Key policy
C. NACL
D. S3 bucket policy

Answer: B
