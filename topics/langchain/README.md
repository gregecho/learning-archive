# LangChain

[LangChain](https://python.langchain.com/docs/introduction/) is a framework for building applications powered by language models. It provides abstractions for chains, agents, memory, RAG pipelines, and tool use.

## Subfolders

| Folder | Purpose |
|---|---|
| [langchain_practice/](langchain_practice/) | Focused exercises covering individual LangChain concepts |
| [langchain_project/](langchain_project/) | End-to-end project applying LangChain in a complete app |
