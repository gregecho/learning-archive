# Flashcards - Cryptography, KMS and Secrets Management

1. Service for automatic secret rotation?
- Secrets Manager.

2. App parameters at lower cost?
- Parameter Store.

3. Key with full customer control?
- Customer-managed KMS key.

4. Which policy is mandatory in KMS?
- Key policy.

5. Encryption at scale uses which standard?
- Envelope encryption.

6. CloudFront certificate in ACM in which region?
- us-east-1.

7. Best practice for app accessing secret?
- IAM role, no hardcoded credentials.

8. Service for dedicated HSM?
- AWS CloudHSM.

9. Key usage auditing?
- CloudTrail.

10. When to use Secrets Manager in the exam?
- When there is a requirement for automatic rotation.
