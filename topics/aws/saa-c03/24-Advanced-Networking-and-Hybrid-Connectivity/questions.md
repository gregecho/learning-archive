# Questions - Advanced Networking and Hybrid Connectivity

## 1)
A company connects 30 VPCs across 10 accounts. Which solution simplifies central routing?

A. VPC Peering full mesh
B. Transit Gateway
C. Shared NAT Gateway
D. PrivateLink

Answer: B

## 2)
Which option allows consuming a private service in another account without full peering between CIDRs?

A. Transit Gateway
B. VPC Peering
C. PrivateLink
D. Internet Gateway

Answer: C

## 3)
Which technology provides dedicated connectivity between data center and AWS with lower latency variability?

A. Site-to-Site VPN
B. AWS Direct Connect
C. NAT Gateway
D. VPC Endpoint Gateway

Answer: B

## 4)
Regarding VPC Peering, which statement is correct?

A. Allows transitive routing
B. Does not allow transitive routing
C. Replaces TGW at any scale
D. Resolves CIDR overlap automatically

Answer: B

## 5)
For high availability in hybrid connectivity, common recommendation:

A. Single DX only
B. Single VPN only
C. Primary DX + VPN backup
D. Public internet only

Answer: C
