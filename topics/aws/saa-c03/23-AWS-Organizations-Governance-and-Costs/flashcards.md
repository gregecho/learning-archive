# Flashcards - AWS Organizations, Governance and Costs

1. Does SCP grant permissions?
- No, it only restricts.

2. Which account is not affected by SCP?
- Management account.

3. Service for multi-account landing zone?
- AWS Control Tower.

4. Central human access across multiple accounts?
- IAM Identity Center.

5. Detailed cost report for queries?
- CUR.

6. Preventive cost alert?
- AWS Budgets.

7. Cost trend and recommendation tool?
- Cost Explorer.

8. Savings with usage commitment?
- Savings Plans/RI.

9. Best use of Spot?
- Interruption-tolerant workloads.

10. Chargeback basis?
- Allocation tags + CUR.
