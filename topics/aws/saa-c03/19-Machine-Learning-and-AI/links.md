## Mind Map: When to Use Each AI Service

| Problem | AWS Service |
|----------|-------------|
| Detect objects in image | Rekognition |
| Extract text from PDF/form | Textract |
| Sentiment analysis of review | Comprehend |
| Text translation | Translate |
| Text to speech | Polly |
| Voice/audio to text | Transcribe |
| Chatbot | Lex |
| Personalized recommendation | Personalize |
| Demand forecasting | Forecast |
| Intelligent document search | Kendra |
| Train custom model | SageMaker |
| Foundation models / LLMs | Bedrock |
