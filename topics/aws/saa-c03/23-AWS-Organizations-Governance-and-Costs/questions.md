# Questions - AWS Organizations, Governance and Costs

## 1)
Which feature prevents member accounts from disabling CloudTrail?

A. IAM Policy
B. Security Group
C. SCP
D. NACL

Answer: C

## 2)
A company wants rapid onboarding of new accounts with a security baseline. Best option?

A. Create accounts manually
B. AWS Control Tower
C. AWS Config only
D. Budgets only

Answer: B

## 3)
For detailed cost visibility by tag and SQL querying, which combination is recommended?

A. Budgets + SNS
B. Cost Explorer only
C. CUR + Athena
D. Trusted Advisor

Answer: C

## 4)
What behavior does an SCP have?

A. Grants permissions automatically
B. Limits maximum permissions
C. Creates IAM users
D. Replaces role trust policy

Answer: B

## 5)
Long-term stable EC2 workload. Best savings strategy?

A. Fixed On-Demand
B. Savings Plans or RI
C. Spot only
D. No autoscaling

Answer: B
