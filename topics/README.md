# Topics

Each subfolder covers one technology. The folder name is the tech name (lowercase).

## Convention

When adding a new topic:

```
topics/
└── <tech-name>/
    ├── README.md
    ├── <tech>_practice/   # Exercises and concept demos
    └── <tech>_project/    # A complete end-to-end app
```

Also add the new folders to `learning-archive.code-workspace` so they appear as named entries in the VS Code sidebar.
