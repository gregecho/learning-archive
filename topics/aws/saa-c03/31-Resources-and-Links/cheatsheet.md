## Exam Registration Process

```
1. Create account at aws.amazon.com/certification
2. Select "Schedule New Exam"
3. Choose: Pearson VUE (in-person or online) or PSI (online)
4. Identify location (in-person) or verify technical requirements (online)
5. Pay: ~$300 USD (with 50% voucher = ~$150)
6. Receive confirmation email with instructions
7. Verify: valid ID (passport/license) + camera + clean environment
8. Result: within 5 business days by email
```

## Strategy During the Exam

```
┌─────────────────────────────────────────────────────────────┐
│  65 QUESTIONS — 130 MINUTES                                  │
│                                                             │
│  1ST PASS (~70 min):                                        │
│    • Read the ENTIRE question before the options            │
│    • Identify keywords (latency, cost, HA, etc.)            │
│    • Answer what you know immediately                       │
│    • MARK doubts (don't spend >2min on 1 question)          │
│                                                             │
│  2ND PASS (~40 min):                                        │
│    • Return to marked questions                             │
│    • Eliminate 2 clearly wrong options                      │
│    • Choose between the 2 remaining by service logic        │
│                                                             │
│  BUFFER (~20 min):                                          │
│    • Very difficult questions                               │
│    • Review answers you felt unsure about                   │
│                                                             │
│  NEVER leave a question blank!                              │
└─────────────────────────────────────────────────────────────┘
```
